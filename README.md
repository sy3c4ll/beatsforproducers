# beatsforproducers.com

Deployed on GitHub Pages at https://beatsforproducers.frii.site, if I set everything up properly of course.

Prototype for internal project, heavily WIP.

This version of the web app uses Svelte with Vite as the bundler. TypeScript and TailwindCSS are also utilised.

To setup:

```sh
deno install
```

To build:

```sh
deno task build
```

For an HMR dev environment:

```sh
deno task dev
```

Or equivalent.
